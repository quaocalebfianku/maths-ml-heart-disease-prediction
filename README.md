# 🧮 Maths for Machine Learning: Heart Disease Prediction

Capstone project for the **AWiMLDS × AIMS Maths for Machine Learning Bootcamp (May–June 2024)**.  
This project applies **mathematics for machine learning concepts** (linear algebra, probability, optimization, and ML fundamentals) to predict the **10-year risk of coronary heart disease (CHD)** using the **Framingham Heart Study dataset**.

## 📌 Project Overview
Cardiovascular diseases are among the leading causes of death worldwide.  
Early prediction of **CHD risk** can help in prevention, lifestyle modification, and healthcare planning.  

This project demonstrates how **mathematical foundations of machine learning** can be applied to:  
1. Identify significant **risk factors** of heart disease.  
2. Build and evaluate a **predictive model** for 10-year CHD risk.  
3. Provide insights into **model interpretability** for healthcare decision-making.  

---

## 📊 Dataset
- Source: [Framingham Heart Study Dataset (Kaggle)](https://www.kaggle.com/amanajmera1/framingham-heart-study-dataset/data)  
- Records: ~4,000 patients  
- Features: 15 attributes including **age, BMI, cholesterol, blood pressure, smoking status, diabetes, glucose levels**  
- Target: `10-year risk of coronary heart disease (CHD)` (binary: 1 = Yes, 0 = No)  

---

## 🛠️ Methodology
1. **Exploratory Data Analysis (EDA)**  
   - Feature distributions  
   - Correlation analysis  
   - Visualization of key trends  

2. **Mathematics for ML Foundations**  
   - **Linear Algebra**: data representation, normalization, feature scaling  
   - **Probability Theory**: risk factor distribution and likelihood estimation  
   - **Optimization**: gradient descent in model training  
   - **ML Basics**: supervised classification  

3. **Model Development**  
   - Classification algorithms (Logistic Regression, Random Forest, etc.)  
   - Hyperparameter tuning  
   - Cross-validation  

4. **Evaluation Metrics**  
   - Accuracy  
   - Precision, Recall, F1-score  
   - ROC-AUC

- Built models to predict **10-year CHD risk** with solid performance.
